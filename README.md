# Broke Ballers data

Game data for the Broke Ballers app: `nba.json` (players on current pro rosters, per-game
stats, cities, and a contract-size index from 0 to 1000 used only to set in-game coin prices;
no dollar amounts). The app downloads it to stay current between app versions.

Nothing about users is here or is ever sent here.

Statistics: Basketball-Reference.com (Sports Reference LLC), via
github.com/sumitrodatta/bball-reference-datasets.
Teams appear by city only. Not affiliated with, endorsed by or sponsored by the NBA, the NBPA,
any team or any player.
